Admin Cloud

Login menggunakan akun admin Supabase. Akun ini terpisah dari PIN admin lokal aplikasi lama.

Pengelolaan PIN mahasiswa

Reset akan menghasilkan PIN acak 4 digit. PIN hanya ditampilkan sekali setelah dibuat; sampaikan secara pribadi kepada mahasiswa.

Untuk mengaktifkan akses admin, akun Supabase Auth harus terdaftar pada tabel admin_users. Jangan bagikan PIN melalui grup umum.

PIN mahasiswa yang baru dibuat

Daftar ini hanya tersedia selama halaman terbuka. Simpan dengan aman dan bagikan PIN secara pribadi.

File CSV berisi kredensial login. Simpan di tempat aman, jangan unggah ke repository atau grup umum.

PIN baru berhasil dibuat

PIN tidak dapat dilihat kembali di panel. Jika hilang, lakukan reset baru.
